SkillBridge API Documentation

Complete API reference for SkillBridge platform

Base URL

http://localhost:8000/api

Authentication Endpoints

POST /auth/register

Register a new user account

Request Body

{
  "email": "user@example.com",
  "password": "securepassword",
  "full_name": "John Doe"
}

Response

{
  "status": "success",
  "message": "User registered successfully"
}

POST /auth/login

Authenticate user and return JWT token

Request Body

{
  "email": "user@example.com",
  "password": "securepassword"
}

Response

{
  "status": "success",
  "message": "Login successful",
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user": {
    "id": 1,
    "email": "user@example.com",
    "full_name": "John Doe"
  }
}

Skill Endpoints

POST /skills/add

Add a new skill for the user

Request Body

{
  "user_id": 1,
  "skill_name": "Python",
  "level": "Advanced",
  "years_experience": 4
}

Response

{
  "status": "success",
  "message": "Skill added successfully"
}

GET /skills/user/{user_id}

Get all skills for a user

Response

{
  "status": "success",
  "data": [
    {
      "id": 1,
      "user_id": 1,
      "skill_name": "Python",
      "level": "Advanced",
      "years_experience": 4
    }
  ]
}

Job Recommendation Endpoints

GET /jobs/all

Get all active job listings

Response

{
  "status": "success",
  "data": [
    {
      "id": 1,
      "title": "Python Developer",
      "description": "...",
      "category": "Software Development",
      "required_skills": "[\"Python\", \"Web Development\"]",
      "salary_range": "80000-120000",
      "company": "TechCorp"
    }
  ]
}

GET /recommendations/user/{user_id}

Get job recommendations for a user

Response

{
  "status": "success",
  "data": [
    {
      "job_id": 1,
      "title": "Senior Python Developer",
      "match_score": 85.5,
      "matched_skills": ["Python", "Web Development"],
      "missing_skills": ["Machine Learning"]
    }
  ]
}

POST /recommendations/generate/{user_id}

Generate ML-based recommendations for a user

Response

{
  "status": "success",
  "message": "Recommendations generated",
  "data": [...]
}

ML API Endpoints

Base URL: http://localhost:5000/api

POST /recommend/skills

Get skill recommendations based on current skills

Request Body

{
  "user_skills": ["Python", "Web Development"],
  "current_level": 2
}

Response

{
  "status": "success",
  "data": [
    {
      "skill": "Machine Learning",
      "reason": "Related to Python",
      "demand_score": 9.5,
      "learning_path": ["Coursera ML Specialization", "Fast.ai", "Kaggle"]
    }
  ]
}

POST /recommend/jobs

Get job recommendations based on skills

Request Body

{
  "user_skills": ["Python", "Machine Learning"],
  "top_n": 5
}

Response

{
  "status": "success",
  "data": [
    {
      "job_id": 2,
      "title": "ML Engineer",
      "category": "Data Science",
      "match_score": 92.5,
      "matched_skills": ["Python", "Machine Learning"],
      "missing_skills": ["Data Science"]
    }
  ]
}

POST /skill-gap

Calculate skill gap for target job

Request Body

{
  "user_skills": ["Python"],
  "target_job_skills": ["Python", "Machine Learning", "Data Science"]
}

Response

{
  "status": "success",
  "data": {
    "matched_skills": ["Python"],
    "missing_skills": ["Machine Learning", "Data Science"],
    "match_percentage": 33.33,
    "gap_percentage": 66.67,
    "learning_priority": ["Machine Learning", "Data Science"]
  }
}

Error Responses

Status Code Description Example Response
400 Bad Request {"status": "error", "message": "Missing required fields"}
401 Unauthorized {"status": "error", "message": "Invalid credentials"}
404 Not Found {"status": "error", "message": "Endpoint not found"}
500 Server Error {"status": "error", "message": "Internal server error"}

Rate Limiting

Currently no rate limiting is implemented. Future versions will include rate limiting per user.

Pagination

Future versions will support pagination with page and limit parameters.
